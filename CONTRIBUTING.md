# Contributing to DreamShell NeXT

Submit NeXT changes to `master` in
[TPMJB/DreamShell_NeXT](https://github.com/TPMJB/DreamShell_NeXT).

different applicable license is expressly identified and accepted before merge.
Changes to separately licensed third-party components retain those components'

Submission does not grant TPMJB, the original DreamShell maintainer, or anyone
else a separate right to commercially relicense your contribution. Any rights

Preserve existing copyright and license headers and the required lines in
[NOTICE](NOTICE). Include the source and license of any third-party material.
See [licensing and attribution](docs/licensing.md) for the scope of these terms.

This policy governs submissions to this NeXT repository. It does not revoke or
amend an agreement previously entered into with another project or rights holder.

## Changes and bug reports

- Describe the problem, the resulting behavior, and how you checked the change.
- Include the NeXT/app version, storage device and filesystem, and steps to
  reproduce a bug. Attach relevant logs without private network credentials.
- For ripping problems, preserve the dump and recovery records. Share logs and
  checksums; do not upload commercial game images to issues or pull requests.
- Keep fixes focused. Run the relevant tests, and state whether you tested on a
  Dreamcast or only on the host. A passing host test is not a hardware result.

The [build guide](docs/building.md) describes automated checks and the complete
build. Release preparation is tracked in [the release checklist](docs/release-checklist.md).
